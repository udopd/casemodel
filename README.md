# CASEMODEL

A local-first web CASE workbench for IDEF0, DFD and IDEF3 process modeling, with an architectural path to ERwin-style data modeling.

Current stage: architecture definition. No application implementation has been started.

See [the architecture baseline](docs/ARCHITECTURE.md) for confirmed requirements, module boundaries, the domain model, diagnostics, persistence, exports, delivery stages and open technical decisions.

The product interface is Russian. Source code and engineering documentation are English.
