# Bundled Fonts

All UI and code fonts are bundled locally inside `public/fonts/` so the exported static workbench requires zero external font requests and supports full Cyrillic coverage offline:

- **Inter** (`400`, `500`, `600`, `700`; `cyrillic`, `cyrillic-ext`, `latin`, `latin-ext`) — sourced from `@fontsource/inter@5.3.0`, licensed under SIL Open Font License 1.1 (`INTER-OFL.txt`).
- **JetBrains Mono** (`400`, `500`, `600`; `cyrillic`, `cyrillic-ext`, `latin`, `latin-ext`) — sourced from `@fontsource/jetbrains-mono@5.3.0`, licensed under SIL Open Font License 1.1 (`JETBRAINS-MONO-OFL.txt`).
